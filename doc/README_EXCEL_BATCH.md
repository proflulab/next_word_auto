# Excel批量导入功能说明

## 功能概述

Excel批量导入功能允许用户通过上传Excel文件来批量生成Word文档。系统会读取Excel中的数据，并将每一行数据填充到Word模板中，生成对应的文档。

## Excel文件格式要求

### 基本格式

- 第一行：字段名（必须与Word模板中的占位符完全一致）
- 后续行：数据行（每行代表一个文档）
- 支持格式：.xlsx 和 .xls

### 示例格式

| 姓名 | 证书编号 | 颁发日期 | 有效期至 |
|------|----------|----------|----------|
| 张三 | CERT001 | 2024/01/15 | 2025/01/15 |
| 李四 | CERT002 | 2024/02/20 | 2025/02/20 |

## 日期字段处理

系统对日期字段进行了特殊处理，支持多种日期格式：

### 支持的日期格式

1. Excel日期格式（推荐）
   - 在Excel中直接使用日期格式的单元格
   - 系统会自动识别并转换为 yyyy/mm/dd 格式

2. 文本日期格式
   - yyyy-mm-dd（如：2024-01-15）
   - yyyy/mm/dd（如：2024/01/15）
   - 系统会自动统一转换为 yyyy/mm/dd 格式

3. Excel日期序列号
   - 系统会自动识别Excel的日期序列号（数字）
   - 自动转换为 yyyy/mm/dd 格式

### 日期处理特点

- 使用UTC时间避免时区问题
- 自动处理Excel的1900年闰年bug
- 支持1900-01-01到2099-12-31的日期范围
- 月份和日期自动补零（如：2024/01/05）

### 日期调试

系统会在浏览器控制台输出详细的日期转换信息：

```
字段 "颁发日期" 的值类型: object 值: Mon Jan 15 2024 00:00:00 GMT+0800
日期转换: Mon Jan 15 2024 00:00:00 GMT+0800 -> 2024/01/15
```

如果日期显示不正确，请：
1. 打开浏览器开发者工具（F12）
2. 查看Console标签页
3. 检查日期转换的输出信息
4. 确认Excel中的日期格式是否正确

## 字段名匹配规则

- 字段名必须与Word模板中的占位符完全一致
- 区分大小写（如：{姓名} 和 {姓名} 是不同的）
- 包括大括号（如：Excel中的列名应该是 "姓名"，对应模板中的 {姓名}）

## 使用步骤

1. 准备Word模板
   - 在模板中使用 {字段名} 作为占位符
   - 例如：{姓名}、{证书编号}、{颁发日期}

2. 准备Excel文件
   - 第一行填写字段名（与模板占位符对应）
   - 后续行填写数据
   - 日期字段使用Excel日期格式或文本格式

3. 上传模板
   - 在"模板选择"区域选择已上传的Word模板
   - 可以点击"预览"按钮查看模板内容

4. 上传Excel文件
   - 点击"上传Excel文件"按钮
   - 选择准备好的Excel文件
   - 系统会显示成功导入的数据条数

5. 生成文档
   - 点击"生成DOCX文档"或"生成PDF文档"
   - 系统会批量生成所有文档并打包下载

## 常见问题

### Q: 日期显示不正确怎么办？

A: 请检查以下几点：
1. Excel中的日期单元格是否使用了日期格式（不是文本格式）
2. 打开浏览器控制台查看日期转换日志
3. 确认Excel中的日期是否在1900-2099年范围内
4. 尝试将日期格式统一为 yyyy/mm/dd 文本格式

### Q: 为什么有些字段没有被替换？

A: 可能的原因：
1. Excel列名与模板占位符不一致
2. 字段名大小写不匹配
3. Excel中的字段名包含了多余的空格

### Q: 支持哪些数据类型？

A: 支持以下数据类型：
- 文本（字符串）
- 数字
- 日期（自动转换为 yyyy/mm/dd 格式）
- 布尔值（true/false）

## 技术说明

### 日期转换算法

```javascript
// Excel日期序列号转换
const excelEpoch = new Date(Date.UTC(1899, 11, 30)); // 1899年12月30日 UTC
const milliseconds = value * 86400000; // 转换为毫秒
const date = new Date(excelEpoch.getTime() + milliseconds);
const year = date.getUTCFullYear();
const month = String(date.getUTCMonth() + 1).padStart(2, '0');
const day = String(date.getUTCDate()).padStart(2, '0');
const formattedDate = `${year}/${month}/${day}`;
```

### Excel解析配置

```javascript
const workbook = XLSX.read(data, { 
  cellDates: true,      // 自动将日期序列号转换为Date对象
  cellNF: false,        // 不使用数字格式
  cellText: false       // 不使用文本格式
});
```
